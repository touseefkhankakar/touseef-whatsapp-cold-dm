# Touseef WhatsApp cold DM skill

Author: Touseef Khan Kakar (@touseefkhankakar)

This skill is tailored to Touseef's lead lists, offers, and existing WhatsApp Business tab. Use it only for a lead list, approved offer, and explicit send request he provides. It does not schedule sends, create follow-up sequences, or authorize sending by itself. Follow any standing authorization Touseef has explicitly given for the current batch.

## Workflow

1. Use the Google Sheet or list Touseef identifies. Work only within the requested batch. If he says to replace numbers unavailable on WhatsApp, continue down that same list only until the requested send count is reached.
2. Keep the existing WhatsApp Web tab and reuse it for every recipient. Never open a new WhatsApp tab per lead. Do not switch to SMS, OpenPhone, or Quo unless he asks.
3. Check each recipient number in WhatsApp. If WhatsApp says it is not registered, record that outcome and move to the next permitted lead. Do not send through another channel as a workaround.
4. Verify the lead's website platform from the live public site or a reliable source. Use the site's own domain and visible technical evidence; do not guess. If it remains unknown, omit the platform name and use the generic wording: “i help teams move sites to custom coded astro”. If the lead has no website, skip it.
5. Use the lead's website URL from the list. Greet with a real person's first name only when the list clearly provides one; otherwise start with “hey” and do not substitute the company name. When there is no first name, keep “hey” and “i was looking through…” on the same line, with no line break after “hey”. Never insert a real company name; if the approved message requires one, use the literal word “company”.
6. Preserve the approved copy, case, punctuation, CTA, and formatting. Use the platform's correct name for each lead. Do not add an opt-out line when Touseef has explicitly rejected it. If he says send now, that instruction overrides a previously chosen local-time window.
7. Before sending, confirm the open chat shows the intended number and that the final rendered message has the correct URL, name rule, verified platform or generic wording, and approved offer. Send one message only.
8. Verify the resulting outgoing message in the visible chat. Record only the state WhatsApp shows; do not call a message delivered or read unless the app shows that status. If the state is ambiguous, inspect the chat and do not retry until resolved.
9. Keep a minimal batch record in existing send-log columns when the user-provided sheet supports it. For a read-only CSV or when no log columns exist, report sent, unavailable, held, and skipped counts without modifying unrelated data.

## Evidence and stop conditions

- Touseef has stated that the leads he provides have the required consent. Do not repeatedly ask him to prove that assertion. Still honor any opt-out, suppression, duplicate, or prior-send evidence visible in the provided records.
- Use only verified personalization. A numeric claim such as a 12-second load time must be supported by a current, lead-specific measurement before sending; do not reuse one number across unrelated websites. Record the measurement source and date.
- Do not promise a 0.3-second load time, higher rankings, or AI-tool visibility unless reliable evidence supports that specific claim for that lead. If approved copy contains unsupported factual claims, hold that message and ask for per-site evidence or an authorized truthful revision. Do not silently rewrite approved copy.
- Stop the batch if WhatsApp displays a restriction, warning, or repeated send failure. If a recipient replies or opts out, record it and suppress further outreach to that recipient.
- Work quickly, but never let a five-second target override recipient, platform, message-accuracy, or send-state checks.
- Keep every claim and proof specific to Touseef's business. Never reuse another company's positioning, metrics, or customer evidence.

## Current campaign preferences

- Keep the outreach in lowercase and preserve Touseef's approved wording and CTA. Use “12s” only when that specific lead's measurement supports it. Mention “0.3s” only when reliable evidence supports that expected result for that lead; a preferred phrase does not verify a performance claim.
- Include a builder name only when verified from the site's live evidence. When the builder is unknown, omit its name and use “i help teams move sites to custom coded astro”; keep the website URL in the opening line.
- Use a person's first name only when clearly present. Otherwise write “hey i was looking through…” on one line, without substituting the company name.

# Touseef WhatsApp cold DM skill

Created and maintained by [Touseef Khan Kakar](https://github.com/touseefkhankakar).

A reusable Codex skill for consent-based, one-to-one WhatsApp outreach. It helps personalize messages from a lead's public website, verify the website-builder platform, and record the message state visible in WhatsApp.

## Install for Codex

```bash
npx skills add touseefkhankakar/touseef-whatsapp-cold-dm --skill touseef-whatsapp-cold-dm --agent codex -g
```

## Requirements

- A lead list and offer supplied by the user.
- WhatsApp Business signed in on the user's device.
- Appropriate consent for promotional WhatsApp messages; honor opt-outs and suppressions.
- Verify factual personalization and performance claims for each website before sending.

This skill does not schedule campaigns or create automatic follow-up sequences.
